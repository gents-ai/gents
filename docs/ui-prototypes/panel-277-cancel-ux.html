Design notes

Tauri command shape

desktop_interrupt_request({
  requestId,
  cause: "userCancelled",     // operator can only authentically produce userCancelled
  cascade: boolean,
  expectedPreviewSignature?,  // only sent when cascade=true
}) -> InterruptRequestResult

InterruptRequestResult — three terminal cases

  • accepted: true — backend latched AgentRequest.interrupt_requested_at. UI closes the dialog, shows a transient "interrupt accepted" notice, transitions the composer button to Cancelled, and surfaces a derived userCancelled badge once the response document lands.
  • alreadyInterrupted: true — another caller (peer, sibling tab, automated policy) latched it first. UI closes the dialog and shows an info notice; no cause downgrade — whatever cause the prior interrupt provided wins.
  • stalePreview: true — the bridge recomputed the preview and the signature changed. UI does not auto-confirm; it redraws the dialog with the fresh preview and a preview updated pill. The operator must press Confirm a second time to commit to the new state.

Why no free cause picker for the operator

The operator can only authentically create userCancelled. deadline and interrupted are derived runtime causes — produced by the deadline tracker and the cascade observer respectively. Exposing a 3-button picker would imply the operator could truthfully mark a deadline or parent-interrupt cause; the runtime does not expose that mutation. The button intentionally bakes in cause: "userCancelled".

Cascade preview auto-redraw (Risk B resolution)

Between preview generation and confirm-click, the underlying tree can shift (a child completes, a new bridge edge appears, a sibling cancels). The previewSignature is a blake3 hash over the root + ordered descendant rows. On stalePreview the dialog re-renders in place rather than dismissing — dismissal would force the operator to rebuild context. The "preview updated" pill makes the change visible; a second confirm carries the new signature.

Accessibility

  • Dialog role: role="dialog" + aria-modal="true" + aria-labelledby pointing to the heading.
  • Focus trap: Tab and Shift+Tab cycle within the dialog. Focus is captured on open and restored to the launching control on close.
  • ESC closes: Both within the dialog and from the composer (composer ESC == click Interrupt, but only after the request id is observed).
  • Announce results: aria-live="polite" region announces "Interrupt accepted", "Preview updated, please re-confirm", etc.
  • Distinct badges: Color is never the only differentiator — every cause badge carries a unique text label, and the unknownPolicy row uses explicit copy ("policy unknown — will be left running, please confirm").

What this prototype intentionally omits

  • Real Tauri command wiring — bridge calls are stubbed to console.log.
  • Operations rail, subagent lineage view, stuck-tool diagnostics (Panels 1, 3, 5 — separate prototypes).
  • Backend deadline countdown clocks — the spec specifies bucketed minute-resolution staleness; this prototype shows static timestamps.

# Tools and context desktop configuration coverage

This matrix follows the generated `Tools` and `AgentContext` types. “JSON” means
the field remains editable in the canonical document editor; it is not a second
configuration shape. Persistence tests exercise explicit Save and projected
reload. Runtime validation remains authoritative.

catalogs are not in `DeploymentView`; the desktop must not invent either list.
Remote/background permissions remain exact-name allowlists, and discovery never
selects newly observed tools.

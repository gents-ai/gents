# Mailbox surface asset

## Installation and authority

`gents pack install mailbox --home <home>` materializes this reusable fragment
under the home's pack assets; it is not a complete desired-state root and does
not write runtime configuration. Incorporate the surface into a document pack
and select it explicitly in the intended behavior's ToolSelection after
reviewing its declared fields. There is no graph or seed in this asset pack.

This desired-state fragment grants the stamped `file_mailbox_item` tool. Packs
copy or reference the surface and explicitly attach `mailbox-writes` to only
the behaviors that may ask their human owner for attention. It is not granted
by default.

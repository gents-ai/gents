For background execution, call `spawn_process` with `{"tool_name":"script","args":{"script":"YOUR JAVASCRIPT","input":{}}}`. Wait on, inspect or cancel it with the process tools. It keeps its caller's tools and runs within that tool's background lifetime, not the foreground allowance. A script started by another script has no `tools`. Once the request has ended, `spawn_process` returns `{ok: false, code: "request_stopped"}` instead of throwing; check `.ok`.

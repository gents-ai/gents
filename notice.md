data_tables pack: third-party notices

The pack embeds no model, font or dataset. Its plugin is a WebAssembly build of this Rust code and the
crates below, each under its own permissive licence (Apache-2.0, MIT or both). Run `cargo tree` in
plugins/data_tables for the full list; `cargo tree -e normal --depth 1` shows the direct ones.

  Apache DataFusion (datafusion and its datafusion-* crates)  Apache-2.0  https://github.com/apache/datafusion
  Apache Arrow for Rust (arrow-*), Parquet (parquet)          Apache-2.0  https://github.com/apache/arrow-rs
  sqlparser                                                   Apache-2.0  https://github.com/apache/datafusion-sqlparser-rs
  tokio, futures, async-trait, serde, serde_json              MIT or Apache-2.0
  chrono, chrono-tz                                           MIT or Apache-2.0
  zip, flate2, miniz_oxide, quick-xml, base64, memchr         MIT or Apache-2.0
  ruzstd (zstd decoding and encoding)                         MIT           https://github.com/KillingSpark/zstd-rs
  snap, brotli, lz4_flex (Parquet codecs)                     BSD-3-Clause, BSD-3-Clause or MIT, MIT

chrono-tz embeds the IANA time zone database, which is in the public domain
(https://www.iana.org/time-zones). The pack's plugins/data_tables/vendor/zstd crate is this repository's own
small stand-in for the `zstd` crate, built on ruzstd, so the plugin links no C code; it is licensed as the
rest of this repository.

Test fixtures under plugins/data_tables/tests/fixtures are generated by plugins/data_tables/tools/gen_fixtures.rs
and contain no third-party data, except formats/people_zstd.parquet, which was written once with the reference
zstd library (BSD-3-Clause or GPL-2.0, library not distributed) to check the decoder against another encoder.
